# AIOStreams (Greek setup)

[AIOStreams](https://github.com/Viren070/AIOStreams) with HTTPS that Stremio accepts, outside access, and the
Greek-subtitles templates preloaded (tablet 1080p and English + Greek). Pairs with the **Greek Subtitles for
Stremio** app.

See the **Documentation** tab for setup, outside access and port forwarding.
