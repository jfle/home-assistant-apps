# Greek Subtitles for Stremio

Real Greek subtitles first — taken from OpenSubtitles and **retimed to the release you play** (delay, frame rate,
cuts / ad breaks) — and an AI translation as backup. Free local model first (LM Studio) when your PC answers, then
your cloud providers in order. Packaged from [AIO-Streams&Subtitles-Greek](https://github.com/jfle/aio-streams-subtitles-greek).

See the **Documentation** tab for setup, outside access and port forwarding.
