# AIOMetadata (Greek setup)

AIOMetadata catalogs and metadata for Stremio on Home Assistant. Open its configure page at home:
`https://<home-ip-with-dashes>.local-ip.sh:8445/configure`. With the **Stremio via Nabu Casa** integration, Stremio reaches it at
`https://<id>.ui.nabu.casa/api/stremio/meta`.
